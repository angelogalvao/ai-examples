# AI Examples Repository

This repository contains examples of multiples AI technologies, like LangChain, iTools, etc, implemented in languages like Python and Java. 

Here is the list of projects:

- **ai-java**: This folder contains multiple AI related projects developed in Java.
- **ilab-example**: This folder contains how to deploy the iLab, IBM/Red Hat, model platform.
- **lang-chain-python**: This folder contains multiple Jupyther notebooks and projects in Python + LangChain
