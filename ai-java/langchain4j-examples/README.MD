## LangChain4J Example project.

This project contains multiple standalone examples on how to integrate with multiples LLM using LangChain4J. 

To execute each class, you should configure the API keys of the following LLM provider as environment variables:

| Provider | API Key env variable |
| -------- | -------------------- |
| Open AI  | OPENAI_API_KEY       |
| Gemini   | GOOGLE_API_KEY       |

Read each class Javadoc to get the details of the example.
